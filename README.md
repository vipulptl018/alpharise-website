# ALPHARISE Website

Official marketing website for **ALPHARISE INNOVATION PRIVATE LIMITED**.

Built with Next.js (App Router), React 19, TypeScript, and Tailwind CSS. Contact form submissions can be routed to the FastAPI backend via `NEXT_PUBLIC_API_URL`.

## Requirements

- Node.js 20+
- npm 10+

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment

See `.env.example`.

| Variable | Purpose |
|----------|---------|
| `NEXT_PUBLIC_API_URL` | FastAPI base URL for contact form (e.g. `http://localhost:8000`) |
| `NEXT_PUBLIC_COMPANY_GSTIN` | Optional GSTIN override |

## Scripts

```bash
npm run dev      # Development server
npm run lint     # ESLint
npm run build    # Production build
npm run start    # Serve production build
```

## Production (Vercel)

1. Connect this repository to Vercel.
2. Set environment variables from `.env.example`.
3. Deploy the root Next.js app (Python `backend/` is excluded via `.vercelignore`).
4. Point DNS for `alphariseinnovation.com` to Vercel.

Optional FastAPI contact API: see `backend/README.md` and deploy separately (Railway, Render, Fly.io, etc.).
