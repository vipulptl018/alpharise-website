# ALPHARISE Website

Official marketing website for **ALPHARISE INNOVATION PRIVATE LIMITED**.

Built with Next.js (App Router), React 19, TypeScript, and Tailwind CSS. The Contact and Newsletter forms post to the FastAPI backend (`backend/`) via `NEXT_PUBLIC_API_URL`; the Next.js app has no form API routes of its own.

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment

See `.env.example`.

| Variable | Purpose |
|----------|---------|
| `NEXT_PUBLIC_API_URL` | FastAPI base URL for the Contact and Newsletter forms (e.g. `http://localhost:8000`) |
| `NEXT_PUBLIC_SITE_URL` | Canonical site URL, the www host (`https://www.alphariseinnovation.com`) |
| `NEXT_PUBLIC_COMPANY_GSTIN` | Optional GSTIN override |

## Production (Vercel)

1. Connect this repository to Vercel.
2. Set environment variables from `.env.example`.
3. Deploy the root Next.js app (Python `backend/` is excluded via `.vercelignore`).
4. Point DNS for `alphariseinnovation.com` to Vercel (`www` is canonical; the bare domain redirects to it).

The FastAPI backend (Contact and Newsletter) is deployed separately, currently on Render: see `backend/README.md` and `README_DEPLOY.md`.
